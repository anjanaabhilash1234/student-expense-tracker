# student-expense-tracker
## Project Description

* A web-based system to manage student expenses and income
* Helps students track spending and savings
* Includes budget management and expense analysis
* Provides reports, charts, and spending insights

## Objectives

* Manage daily expenses efficiently
* Track income and expenses securely
* Categorize expenses for better organization
* Set and compare monthly budgets
* Analyze spending patterns using reports
* Compare UPI and cash expenses
* Encourage saving habits
* Predict future expenses

## Technologies Used

* Programming Language: Python
* Framework: Django
* Frontend: HTML, CSS, JavaScript
* Database: SQLite / MySQL
* IDE: Visual Studio Code

## Modules

### Student Module

* Login and registration
* Expense tracking
* Income management
* Budget management
* UPI vs cash analysis
* Reports and charts
* Saving suggestions

### Admin Module

* Manage users
* Manage categories
* View reports
* Manage feedback

## Features

* Secure login system
* Expense and income tracking
* Budget comparison
* Expense categorization
* Reports and graphical analysis
* Saving suggestions
* Future expense prediction

## Scope

* Helps students manage finances
* Reduces unnecessary spending
* Improves budgeting habits
* Supports better financial planning
